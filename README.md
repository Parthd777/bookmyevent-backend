# BookMyEvent Backend - Day 1

This branch implements the Day 1 deliverable: a console-based Java event booking application with in-memory style collections, custom exceptions, and file persistence.

## Features
- User registration
- Venue creation
- Event creation
- Event listing
- Seat booking
- Booking listing
- Data persistence to local text files under the data directory

## Run
```bash
mvn exec:java
```
